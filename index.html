コマ割りメモへようこそ

箇条書きのメモから、マンガのコマ割りを作ってクリスタに持っていけます。4ステップだけです。

1
メモを書く左の欄に箇条書きで入力。Enter で次の行、Tab で字下げ。
2
コマに分ける行にカーソルを合わせると出る「✂ ここから次のコマ」を押すと、そこからが次のコマに。1枚のカードが1コマです。
3
大きさを調整右のコマをクリックして「小〜大」を選ぶだけ。ページ全体が自動できれいに割り直されます。
4
書き出す右上の「⬇ 書き出す」から。クリスタEXなら PDF で全ページを一括で取り込めます。

最初はサンプルが入っています。自由に触ってみてください（間違えても「↶ 元に戻す」で戻せます）。

名前を付けて保存

ファイルの名前を入力してください。

このあとブラウザの確認が出たら「ダウンロード」を押してください。ファイルは「ダウンロード」フォルダに入ります。

✓ 自動で保存されています

入力した内容は、この端末のブラウザに自動で保存されています。保存の操作は必要ありません。閉じたファイルは「📂 ファイル一覧」から開けます。

別の端末で使うときや、バックアップを取りたいときは「名前を付けて保存」でファイルにできます。

ファイル一覧

この端末で作ったファイルは、すべてここにあります（タブを閉じたものも含みます）。

別の端末から持ってきたファイルを開くときだけ「端末のファイルを開く」を使います。書き出したファイルは「ダウンロード」フォルダにあります。.json 以外は開けません。

用紙設定

クリスタで作る作品と同じ値にしておくと、書き出した画像がぴったり重なります。

  • 仕上がり：白い部分。本になったときの紙の大きさ
  • 裁ち落とし：灰色の部分。印刷で切り落とされる余白
  • 基本枠：青い点線。コマはこの中に並びます
  • 書き出す画像の大きさ ＝ 仕上がり＋裁ち落とし

用紙

コマの並び

見た目

テキストでまとめて入力

1行が1項目になります。--- の行でコマを分け、=== の行でページを分けます。行頭の「- 」「・」はあってもなくてもOK。スペース2つで字下げ。

使い方

1. メモを書く

  • 左のカードに箇条書きで入力します。Enter で次の行、Tab で字下げ、Shift+Tab で戻す。
  • カード下の「＋ 行を追加」、いちばん下の「＋ コマを追加」「＋ ページを追加」でも増やせます。
  • 複数行の文章を貼り付けると、1行ずつ項目になります。

2. コマに分ける

  • 行にカーソルを合わせると出る「✂ ここから次のコマ」で、その行から下が次のコマになります。
  • 文の途中で分けたいときは、分けたい位置にカーソルを置いて Ctrl+Enter（ページごと分けるなら Ctrl+Shift+Enter）。
  • カードをクリックすると操作ボタンが出ます。「📄 改ページ」でそのコマからページを変え、「⤒ 前とつなげる」で区切りを消せます。
  • 1ページの最大コマ数（初期値6）を超えると自動で次のページに送ります（用紙設定で変更可）。

3. 大きさを調整

  • 右のコマをクリックすると「小 ①〜⑤ 大」が出ます。カード上部の ●○ でも変えられます。数字キー 1〜5 も使えます。
  • 大きさに合わせてページ全体が自動で割り直されます。ページ上の「次の割り方 ▶」で別の並べ方の候補に切り替えられます。

コマの入れ替え・削除

  • 入れ替え：右のコマを別のコマへドラッグすると、中身が入れ替わります（コマの形はそのまま・別のページへも可）。スマホは長押しして、枠が青く光ったら指を動かします。
  • 並べ替え：左のカードの ⠿ をドラッグすると好きな位置へ移動できます（大きさもカードと一緒に移動）。スマホはカードのどこを長押ししても動かせます（入力中の行を除く）。カードを選ぶと出る ▲▼ でも1つずつ動かせます。
  • 削除：カードの「🗑 削除」か、右のコマの右下の 🗑。コマを選んで Delete キーでも消せます。
  • 元に戻す：間違えたら画面左上の「↶ 元に戻す」（Ctrl+Z）。ページを開き直したあとでも戻せます。
  • 別のファイルへ移す：カードを選んで「⧉ コピー」か「✂ 切り取り」を押し、タブを切り替えて、貼りたい場所のカードの「📋 貼り付け」または下の「📋 最後に貼り付け」。コマを選んだ状態なら Ctrl+C / X / V も使えます。大きさも一緒に移ります。

4. 書き出してクリスタへ

  • クリスタEX（おすすめ）：「⬇ 書き出す」→ PDF。クリスタEXで複数ページ作品を開き、「ストーリー → ページの取り込み」でPDFを選ぶと、変換設定のあと各ページが1ページずつ追加されます。作品と同じ解像度を指定してください。
  • PNG：ZIPを展開した page_001.png… を、各ページで「ファイル → 読み込み → 画像」。画像には解像度情報が入っているので、キャンバスと同じ設定ならぴったり重なります。
  • 枠線は画像として入ります（クリスタのコマ枠フォルダーには自動変換されません）。複数ページ作品と「ストーリー」メニューは EX の機能です。PDF の取り込みが見当たらない場合は、クリスタを最新版に更新するか PNG を使ってください。

ファイルと保存

  • 複数ファイル：上のタブがファイルです。「＋」で新しいファイル、タブのクリックで切り替え、ダブルクリックで名前を変更できます。
  • 閉じる：タブの × で閉じても消えません。「📂 ファイル一覧」からいつでも開き直せます。不要になったら一覧の「削除」で消せます。
  • 上書き保存：Ctrl+S または「💾 保存」。最初に名前と保存先を決めると、次からは同じファイルに上書きします（パソコンの Chrome / Edge）。
  • スマホ・Safari・Firefox：自動で保存されるので、保存の操作は要りません。ファイルとして残したいときは「ファイル → 名前を付けて保存」を使います。確認が出たら「ダウンロード」を押してください。
  • 自動保存：入力内容は常にこのブラウザの中に自動保存されます。ただし端末どうしでは同期されず、ブラウザのデータを消すと失われます。別の端末に移すときや大事な節目には、ファイルとして保存してください。
  • ファイルを開く：パソコンでは今のファイルと同じフォルダから始まり、.json だけが表示されます。保存した .json は画面にドラッグ＆ドロップしても開けます。スマホでは、まずファイル一覧から選びます。別の端末から持ってきたファイルだけ「端末のファイルを開く」で探します。
